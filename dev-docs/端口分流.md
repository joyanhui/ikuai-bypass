## protocol 字段说明

通讯协议，可选值：
- `tcp+udp` （默认）
- `tcp`
- `udp`
- `icmp`
- `任意`（API 中使用 `any`）

## src_addr / dst_addr 格式

- `custom` 只放 IP、IP 范围或 CIDR，例如 `192.168.1.10-192.168.1.254`。
- `object` 放 IP 分组引用，元素格式为 `{"type":0,"gid":"IPGP{id}","gp_name":"分组名"}`，其中 `gid` 是爱快返回的 IP 分组标识，`gp_name` 是分组名。
- 分组名只能通过 `object` 引用，不能放进 `custom`。分组名可能包含 `-`、`.`、`:`（如 `FW-LAN`），这些字符不代表 IP 范围，放进 `custom` 会被爱快拒绝并返回 `请求参数不合法`。
- `src-addr-opt-ipgroup` 优先生效并覆盖 `src-addr`：配置后源地址全部按 IP 分组引用发送，`src-addr` 的 IP 列表被忽略。
